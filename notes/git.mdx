## Basic


<HighlightText>Main has new commits now</HighlightText>

```bash
main:
A --- B --- C --- F --- G

feature:
             D --- E
```

Rebase your feature branch onto latest main (cleaner history)

```bash
A --- B --- C --- F --- G

feature:
                         \
                          D' --- E'
```

```bash
git stash -u
git fetch
git rebase origin/main
git stash pop
```

Merge main into your feature branch (simpler, preserves history)

```bash
A --- B --- C --- F --- G
             \           \
              D --- E --- M
```
