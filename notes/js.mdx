## Type coercion


<HighlightText>Coercion to String</HighlightText>

```js
console.log(11 + "1"); // "111" (string)
```

Whenever the binary + operator is used with a string on either side, JavaScript defaults to `string concatenation`

```js
console.log([] + []) outputs an empty string ("").
```

When using the addition operator (+) on objects or arrays, it call `.toString()` method.

<HighlightText>Coercion to Number</HighlightText>

```js
// Arithmetic operators (-, *, /, %)
'10' - 2         // 8
'6' * '2'        // 12
'10' / null      // Infinity (10 / 0)

// Unary Plus (+):
+'42'            // 42
+true            // 1
+false           // 0
+null            // 0
+undefined       // NaN
+null            // 0
+[]              // 0
+{}              // NaN

// Relational Comparison Operators (>, <, >=, <=):
'10' > 5         // true 
'20' <= '3'      // false
```


<HighlightText>Coercion via Loose Equality</HighlightText>

| Comparison          | Coercion Behavior                                          | Example                                                    |
|---------------------|------------------------------------------------------------|------------------------------------------------------------|
| String == Number    | Converts String to Number                                  | '42' == 42 -> true                              |
| Boolean == Anything | Converts Boolean to Number first                           | true == '1' -> 1 == 1 -> true        |
| Object == Primitive | Converts Object to Primitive via .toString() or .valueOf() | ['a'] == 'a' -> "'a' == 'a'" -> true |

## let and var in for loop

```js
for (var i = 1; i <= 5; i++) {
  setTimeout(function() {
    console.log(i); // This function forms a closure
  }, i * 1000);
}
// Output: 6, 6, 6, 6, 6 (printed after 1, 2, 3, 4, 5 seconds)

for (let i = 1; i <= 5; i++) {
  setTimeout(function() {
    console.log(i); // This function forms a closure
  }, i * 1000);
}
// Output: 1, 2, 3, 4, 5 (printed sequentially after 1, 2, 3, 4, 5 seconds)

```

## Single pattern

```js
const SingletonClassic = (function () {
  let instance;

  function createInstance() {
    let isRunning = false;

    const start = () => (isRunning = true);
    const stop = () => (isRunning = false);
    const status = () => console.log(isRunning);

    return { start, stop, status };
  }

  instance = createInstance();

  return {
    getInstance () {
      return instance;
    },
  };
})();

const instanceA = SingletonClassic.getInstance();
const instanceB = SingletonClassic.getInstance();

instanceA.status() // false
instanceB.status() // false

instanceB.start()

instanceA.status() // true
instanceB.status() // true

```

## Closure

```js
function f1() {
  for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 1000 * i); // 3 3 3
  }

  // i still access there
}

function f2() {
  for (let i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 1000 * i); // 0 1 2
  }

  // can;t access i there
}

// Using bind
function f3() {
  for (var i = 0; i < 3; i++) {
    setTimeout(((x) => console.log(x)).bind(null, i), 1000 * i); // 0 1 2
  }
}


// Using IIFE
function f4() {
  for (var i = 0; i < 3; i++) {
    setTimeout(
      (
        (x) => () => console.log(x) // 0 1 2
      )(i),
      1000 * i,
    );
  }
}

```

## Hoist

```js

const print = () => {
  console.log(x); //undefined
  var x = 10;
};

```

**var** it's hoisted and assigned **undefined** as default value

**let** and **const** also hoisted but has no default value

## This keyword

Arrow function is lexical scope

```js
const obj = {
  a: "object value",
  foo: () => {
    console.log(this); // {}
  },
  bar: function() {
    console.log(this); // {a: "object value"}
  }
};
```
